## التقاط لقطة جديدة (الحجم الصحيح مباشرة)

```bash
# iPhone 17 Pro Max → 1320×2868
xcrun simctl io 74A14C2F-7048-4013-B34E-DDC321521816 screenshot \
  app-store-screenshots/iphone-6.9/03-live.png

# iPad Pro 13″ → 2064×2752
xcrun simctl io B3BE91AA-CC07-4E5C-92D8-B642C8324ECF screenshot \
  app-store-screenshots/ipad-13/02-main.png
```

سجّل الدخول على Pro Max والآيباد أولًا، افتح الشاشة المطلوبة، ثم نفّذ الأمر.

## الرفع لآبل

1. Archive من Xcode (Any iOS Device) → Distribute App → App Store Connect  
2. ارفع اللقطات من Connect → نسختك → لقطات الشاشة  
3. لا ترفع لقطات فيها بيانات تجريبية حسّاسة أو حسابات حقيقية ظاهرة بلا موافقة
